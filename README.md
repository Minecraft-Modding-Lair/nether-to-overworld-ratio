# nether-to-overworld-ratio

Travelling 1 block in the nether can replace the distant of 8 blocks in the overworld, making trips in the nether 8 times faster! With this mod, you can configure the said distant to what ever you would like.

## Available Versions

| Version | Fabric | NeoForge |
| ------- | ------ | -------- |
| 1.21.1  | ✅     | ✅       |
